# 本次创作过程与经验

此记录最初来自 2026-10-21 完成的 *Simplicial closure and higher-order link prediction* 论文解读，并补充后续案例。它解释本技能的来源与修订依据；其中论文事实、版本、数值和风格不得直接带入另一篇论文。

下文的早期案例记录中文配音及双版本制作历史，不规定当前流程。当前默认交付单个英式英语配音、中文字幕的视频，不再要求中文配音版；以 [技能入口](../SKILL.md) 和 [制作流程](production-workflow.md) 为准。

## 从论文到成片的演进

| 阶段 | 发生的调整 | 提炼出的经验 |
|---|---|---|
| 论文解读与首版 | 围绕群体事件、单纯形闭合、高阶链接预测，结合原图、公式和教学示意制作 Remotion 视频 | 先理解研究对象和任务定义，再组织方法及结果；不把普通图上的关系直接等同于真实共同事件 |
| 改善配音 | 用户认为原 Tingting 配音不自然，换为云端云扬男声；听过短样片后回复“听感合适” | 音色影响长视频体验；试听包含概念与数字，后续沿用已确认参数，不重复确认 |
| 增加开场导览 | 补入论文原题、PNAS、发表日期、五位作者、署名单位、主要内容和观看路线 | 用户需要先知道在读什么论文；书目卡承担导览作用，并避免正文重复介绍 |
| 自然中英混用 | 用户明确不必强制全中文；题目、作者、PNAS、MIT、方法和指标改用原名 | 字幕和旁白都支持双语表达，中文解释不意味着把专名全部音译 |
| 修复英文字幕 | 解决 `higher-order` 等词被切开的问题，让画内字幕和 SRT 共用断行 | 同时检查词语时间边界与显示换行边界，两个输出不能各用一套断句算法 |
| 增量生成与验收 | 66 段中重做 7 段，其余 59 段音频逐字节复用；重新生成时间轴后导出整片 | 只重做受影响内容，更新字幕、章节与总时长；验证逻辑也要反映实际修改范围 |
| 整理多论文工程 | 根目录只留 `paper/`、`remotion/`，每篇论文在后者内单独建目录 | 从第一篇建立隔离边界，避免下一篇混用源码、缓存和输出 |
| 清理历史过程 | 保留当前视频和可运行工程，删除旧版、试听、截图及多余缓存，净释放约 3.64 GiB | 先检查依赖和保留项哈希，再清理；同步去掉校验脚本和文档对已删文件的依赖 |

最终版本为 15 分 22.1 秒、1080p、30 fps，11 章、66 个分镜、183 条字幕。开场约 61.4 秒，原论文 Table 3 的 152 个数值逐项核对。这些规模来自该论文的讲解选择，不应成为其他论文的验收门槛。

## 哪些细节改善了结果

**资料与解释分开。** 原图保留来源、图例和坐标；两种事件历史、三角形闭合及均值排序示意按定义构造，标记为教学例子。视频明确候选集合、时间切分和随机基线倍数，避免把结果说成准确率或因果发现。

**按段合成，按词对齐。** 保存完整段落的原始 MP3、48 kHz PCM 与 WordBoundary，由实际采样数确定帧数，字幕、音轨和章节共享时间轴，没有用后期变速凑时长。

**英文原名贯穿音画。** 开场使用英文完整标题，作者姓名保留原文，Adamic–Adar、Katz、Personalized PageRank、AUC-PR 等进入中文讲解。首次出现可配中文解释，之后不要求机械重复双语。

**增量检查音频与版式。** 改文只替换相关缓存，长英文方法名在真实图表和字幕中检查。封面原先写死的时长改为读取时间轴，避免视频更新后封面仍显示旧片长。

**保留阶段证据。** 整片解码、多处音频同步、66 个分镜抽帧和片尾检查分别记录。用户认可原试听，没有被扩大成“新英文内容已获确认”或“整片已人工听审”。

## 后续案例：段落对齐与动画语义错位

2026-10-28 对 P0011 *Towards Better Evaluation for Dynamic Link Prediction* 英文成片进行了局部只读诊断。约 03:35 旁白讲第三个时刻，主图只亮到 t2；约 03:48 讲 AC 和 CE，主图只亮到含 AC 的 t4，CE 所在的 t5 仍为暗色。实际 MP4 抽帧、词级时间信息和渲染源码快照相互印证，抽查位置的成片音轨与原始配音未测得偏移。

实现将四段旁白各生成一个动画阶段，再以固定数组映射到 t1、t2、t4、t6；实际第一段涉及 t1 和 t2，第二段讲 t3，第三段讲 t4 与 t5。词级时间信息已保存，但动画只使用段落起点，因而字幕与侧栏同步仍可伴随主图错位。相邻段落讲论文的 70/15/15 划分时，主图继续展示教学例子的三步训练、三步测试，仅增加比例文字，图示也未对应当前讲解对象。

此前波形检查与编码静帧比对未覆盖这些关键转换，代表静帧检查没有逐句核对段内变化。可复用的改进是：按具体词句定义视觉动作与目标状态，并围绕语义转换检查主图，分别记录技术同步和内容对应的证据。流程见 [语义动作与动画触发](production-workflow.md#语义动作与动画触发) 与 [Remotion 渲染与交付](production-workflow.md#remotion-渲染与交付)。此案例仅确认局部问题；当次未修改或重渲染视频，也未完成整片语义同步审查，所列时刻和事件数量不构成通用检查模板。

## 后续案例：关键词提纲式画面与篇幅失衡

2026-11-15 的只读回顾核对了论文库 13 个已交付英文视频的实际时长，并检查 P0007、P0011、P0013、P0014、P0015 的讲稿、章节时间轴和代表画面。视频长度约为 23 分 37 秒至 34 分 05 秒；最近三篇除开场外均采用四段解说，P0015 的 30 个正文分镜每个约 46–54 秒。这些观察显示近似等长展开的倾向，但不等于对所有视频完成了全程观看或逐帧审查。

P0015 的 related work 展示了论文标题与作者年份，具体做法和彼此关系却被压缩到侧栏短句；证据讨论的主画面放大“Exchange contribution”，没有同时呈现支撑判断的实验对照。引用存在、字幕完整和动作同步，都不能证明主画面已经承担了实质解释。改进应落实到具体信息及其关系，单纯把关键词卡片排成表格仍可能保留同样问题。

| 回顾发现 | 可复用的改进方向 |
|---|---|
| 前人研究有书目信息，机制与贡献难以对应 | 用研究比较表连接任务、具体做法与本文问题；像 FunSearch 的岛屿演化与重新播种这类关键前置机制，可独立动画解释，再连接到本文设计。实际制作前仍核对原始研究，不能把此例的机制套到其他论文。 |
| 多个结果或辅助说明获得近似相同篇幅 | 按贡献与理解依赖分配时间，用同一例子贯穿方法和评价，集中比较相似结果、重点解释例外；不把每页四段解说或约一分钟作为模板。 |
| 缩短视频可能误删最有解释力的例子 | P0007 的“相同归因、相反局部方向”曲线和 P0011 的“固定预测分数、改变负例池”算例具有明确解释作用，应优先保留核心例子及条件，压缩外围重复展开。 |

用户据此选择主画面支持暂停后充分阅读，关键 related work 可用独立动画，篇幅优先约 15 分钟、通常争取在 20 分钟内，同时保留不同论文所需的弹性。当前原则见 [核心内容与时长](production-workflow.md#核心内容与时长) 与 [画面与素材](production-workflow.md#画面与素材)；这些是编辑取舍依据，不形成固定片长、分镜数或动画数。此次回顾及技能更新未修改或重渲染这些历史视频，也不表示优化后的成片效果已经得到验证。

## 本机排障记录，不作通用依赖要求

- 本项目验证过 Remotion 4.0.537、React 19.2.0 和 macOS arm64 的 Chrome Headless Shell 149.0.7790.0。另一套较新浏览器曾出现 Root 加载超时，最终使用项目内验证过的浏览器。新环境应重新核对兼容性，不盲目固定到 149。
- 云扬使用 `zh-CN-YunyangNeural`、语速 `+0%`、音高 `+0Hz`，客户端 edge-tts 7.3.1。它是第三方客户端连接在线服务；无个人 API Key 不等于永久可用或稳定性承诺。
- 目录移动后，Python 虚拟环境入口仍可能指向旧位置；在最终目录重建环境后，含空格的论文文件夹也能正常使用。
- 纯目录迁移没有重做旁白或完整视频。新位置的 12 秒 Remotion 样片解码正常，三处抽帧与既有成片像素一致；PDF、视频、字幕、封面、音轨等保留项哈希未变。
- 清理还发现重复 bundle、下载压缩包和未使用的浏览器缓存。当前被引用的语音缓存与已验证环境继续保留；不是删除整个 `.cache/` 就算完成。

## 避免将案例变成无关约束

这次配色、图形类型、片长和章节服务于一篇网络科学论文。其他学科应重新设计视觉解释；会议论文、预印本和理论论文按自身事实组织导览与论证。

这次用户明确授权清理历史版本，不能推断未来新建视频时可以删除其他项目。云扬的试听认可属于历史中文配音任务，仅在用户再次明确要求中文配音时参考；当前默认英文声线以技能入口为准。
