# 论文解读视频制作流程

按当前任务读取对应部分：英文配音与中英双语字幕、英文主笔记、论文与讲稿、研究背景与动机、画面、声音和字幕、渲染交付、增量修改、目录与清理。本文件描述应实现的能力，不要求每个项目具有相同脚本名或数据结构。

## 英文配音与中英双语字幕

新建完整论文解读时，执行“论文研读、背景论证核对与证据整理 → 核心解释、主画面与篇幅设计 → British English 讲稿与配音 → 对应中英双语字幕、动画与完整成片 → 内容、画面信息与技术及语义同步验收 → 单个视频交付”。默认交付一个英式英语音轨配中英双语字幕的视频；成片数量、配音语言与字幕语言分别记录和判断。只要求一个英文配音版本时继续保留中英双语字幕；当次明确要求单语字幕时，按指定语言制作。用户当次明确要求优先；沿用已确认的声音与语速，不新增必须等待批准的关卡，用户明确要求先试听确认时除外。

英文讲稿直接依据论文与研读记录组织，使用自然的英式英语措辞、拼写和发音，保留专名的正式拼写。英文字幕对应实际旁白的词句，中文字幕翻译同一段英文内容，用自然中文表达同一含义与论证顺序，保留否定、限定条件、关键数值及结论强度。避免生硬照搬英语句式，也不能将字幕改写成独立讲解、额外补充内容或只保留概括而遗漏重要信息。

英文原句与中文译文在工程中按语义组成成对字幕单元，共用对应英文语音的起止时间，并在画面中同时显示。已有工程沿用合适的双语布局，新工程默认英文在上、中文在下；按画面宽度、字号和阅读时间调整分段与换行，避免遮挡主图。标题、图表标签、论文题目、人名及术语可自然保留英文；中文解释以帮助理解为准，不强行全中文。

在英文主笔记中记录核心内容的位置、时长、成片入口及必要的字幕翻译说明，供制作核对使用。历史中文配音或双版本工程按当前修改范围处理；已有英文音轨合格时可复用，不能直接拿历史独立中文讲稿当作英文旁白的字幕。更新技能不自动删除、合并或重做历史版本。

## 英文主笔记

新建完整作品时，在论文工程内建立 `docs/paper-notes.md`，用英文记录论文理解与视频设计，作为共同研读、制作和后续跨论文回顾的主要入口。已有同等用途的英文笔记可整合沿用，保持一个明确的主入口并在工程 README 中链接。笔记应包含可独立理解的归纳，不仅是待办、链接或制作日志。

在讲稿编写前完成研读与设计初稿，制作中随理解和设计变化更新，交付时补齐实际内容与产物。采用以下稳定栏目，便于按时间、主题和研究问题回顾多篇论文：

| 英文栏目 | 记录内容 |
|---|---|
| Paper Identity | 原题、作者、发表载体与日期、DOI、指定 PDF 的路径与版本、研读日期、主题标签及简短摘要。 |
| Understanding | motivation 与具体问题、由问题导出的比较维度、前人进展的归纳及具体 research gap、本文回应、核心方法、结果与局限；重要论断对应原文位置，区分作者评价与解读者归纳。 |
| Prerequisites and Explanation | 理解本文所需的基础概念、术语解释、教学例子，以及类比的适用边界。 |
| Video Design | 核心结论与解释依赖、内容取舍和章节逻辑、相关研究的前置归纳及入选研究的解释作用、主画面要呈现的判断与依据、必要机制和动画、预计时长；必要的语言适配记录仅供制作使用。 |
| Connections and Open Questions | 与确实读过的其他论文的联系、可比较维度和待解决问题，区分作者结论与解读者归纳；没有可靠联系时如实留待后续补充。 |
| References and Delivery | 与画面作者年份引用对应的完整书目、可追溯链接、关键原文定位、详细证据记录入口，以及最终视频入口和实际时长。 |

现有详细来源映射、阅读与下载状态、代码检查、验收记录通过链接关联，保持证据可追溯，避免重复抄写到主笔记。主笔记随工程长期保留，清理缓存时不得作为过程文件删除。后续局部修改更新已有笔记中受影响的部分；补建历史论文笔记按当前请求范围处理。

## 论文与讲稿

确认用户指定的 PDF、版本和项目；有现成工程时先查来源记录和当前输出，不从空模板覆盖已有内容。记录 PDF 哈希、书目信息、实际阅读范围，以及重要论断对应的页码、图号、表号或公式。

书目信息须区分在线发表、卷期出版、接收和投稿日期；预印本没有正式发表载体时如实标注，不补造期刊信息。作者单位采用论文发表时的署名，姓名保持原文拼写。开场的信息取舍按下述“简短开场导览”执行。

正文围绕具体研究问题推进，依据“研究背景、Research Gap 与 Motivation”解释本文要解决什么及其来由。基础概念和关键前人机制可以在相关内容首次需要时展开，确保观众理解当前设计、证据与结论条件；不必把全部背景和定义讲完才展示核心问题或直观例子。学科与论文类型不同，组织方式可以不同。

对实验论文，讲清样本或候选范围、切分方式、标签、指标和比较基线。相对提升不等于准确率，观察关联不等于因果，教学构造不等于实验结果。对理论论文，明确定义、假设、命题和证明思路，不硬套实验结构。强调的数值逐项回查原文；表格较多时可在具体项目中采用自动比较。

### 核心内容与时长

未另指定时，优先将论文解读组织为约 15 分钟、通常争取在 20 分钟以内的集中讲解。实际时长由核心贡献、必要前置知识和关键证据的解释需要决定；这些数字用于编辑取舍，不作为硬性验收阈值，也不另设固定浮动区间。信息简洁时可以更短，必要推理或复杂机制需要时可以更长；用户当次明确时长优先。

围绕研究问题、必要背景与 research gap / motivation、核心方法、关键证据和结论边界组织主线。决定是否展开某项细节时，判断它是否影响观众理解核心贡献或判断证据强弱。优先保留能说明机制的例子、决定结论的对照和必要限定；次要实验、重复结果、常规实现细节和非关键推导可概括或省略。辅助细节与原文定位保留在英文主笔记或其链接的证据记录中，便于回顾。

先确定观众需要理解的核心结论，追溯必要概念、前人机制与决定性证据，再安排分镜和讲稿。篇幅按解释难度与重要性分配，不默认每页等长、每段四句或每个分镜四段解说。尽量用一个具体例子贯穿任务、方法和评价；相似结果集中比较，差异和例外重点解释；多个应用任务可选择代表任务完整展开，再概括其他任务提供的补充证据。关键前人研究的动画计入这条解释主线，用它替换重复铺垫，不自动额外增加一轮背景介绍。

精简展开范围，同时保留初学者理解主线所需的术语解释、具体例子和阅读停顿。影响结论的假设、失败情形和证据局限随对应论断讲清，避免在多页反复改写同一限定；新的适用条件仍需说明。保持自然语速，不靠加速或删去关键条件缩短视频。主画面可保留暂停后可读的比较信息，旁白集中讲关键关系与发现，无需逐项朗读表格。

配音前在已有 Video Design 中记录核心解释与取舍、related work 的归纳及必要例证、主画面要解释的判断与依据、关键机制和预计时长。沿用现有笔记，无需逐项登记所有未入选引用，也无需新增文件或固定字段格式。篇幅明显增加时，先检查重复说明、次要结果和实现细节，再简述保留必要展开的内容依据；不要求为偏离常见时长另行申请批准。配音后依据真实音频及最终时间轴复核整片长度，包含开场、停顿和转场。

### 简短开场导览

将论文基本介绍与视频内容总览合计控制在约 30 秒，通常按 25–35 秒规划。从首帧到进入实质论文讲解共同计时，包含片头、书目介绍、总览、停顿与转场；不能给介绍和总览分别安排约 30 秒，也不在简短片头后再追加冗长的内容预告。用户当次明确要求优先。

画面展示论文原题、作者信息、期刊或会议及发表时间；旁白简述研究主题、值得关注的问题，并用一句话概括讲解路线。无需逐项朗读全部作者、单位和章节目录。长标题可在画面保留原题，旁白使用清楚的简称；作者较多时展示代表作者及“等 / et al.”，完整名单与署名信息在英文主笔记中保留。按实际字号检查可读性，不靠堆叠小字塞入信息。

具体问题示例、必要基础、前人研究、research gap 与 motivation 在正文展开，仍须在核心方法前建立充分理解；开场时间目标不限制这些正文内容。配音前删减重复介绍和空泛预告，配音后依据英文配音的真实音频与最终时间轴核对开场时长，超出目标时优先精简内容，不靠加速语音压缩，也不为凑满 30 秒填充内容。在已有视频设计或验收记录中记载实际开场时长，无需新增数据格式或人工批准环节。

### 面向初学者的解释

默认观众没有本领域及核心方法的专业基础。围绕理解本文必需的知识建立直觉，避免连续使用未解释的术语，也不扩展成完整学科课程。

- 从具体问题与可跟随的例子引入概念，再给出必要的术语和符号。缩写首次出现时说明含义及其在本文中的作用，仅展开英文全称通常不够。
- 讲清方法的输入、关键处理和输出。公式说明符号与运算含义，必要时用小规模算例或逐步动画展示；保留核心假设及推理，避免用类比替代科学定义。
- 解释实验任务、比较对象和指标衡量的内容，交代数值对应的样本或分母，使观众能判断结果支持什么。按需要补充图、概率或领域概念的基础解释。
- 用画面呈现关系与变化，给新概念、公式和引用留出阅读时间。沿主要论证检查是否存在知识跳跃，使初次接触这些概念的观众能够复述研究问题、主要方法、关键结果及其局限。

### 成片内容与制作记录

旁白、字幕文案、片头、常驻页脚、片尾和视频封面集中呈现研究内容，不主动展示 British English、UK narration、英文配音、中英双语字幕等制作标签。语言、声线与字幕要求照常落实；文件名、工程配置及外部播放入口可保留必要的语言标识。

制作者检索过哪些文献、下载成功或失败、读了哪些页、核查步骤和制作工具等过程信息留在工程记录中。判断某项前人研究有助于理解本文后，直接介绍其问题、贡献及与本文的联系，并配参考文献；引用需要的页码、图号等来源定位可以显示。论文自身的方法若包含文献检索、筛选或知识图谱构建，应照常解释这些研究步骤。

科学条件、作者观点归属及影响结论的不确定性仍需清楚。资料不足时缩小讲解范围，或限定为有依据的作者表述，不将未核实内容说成确定事实，也不播报下载失败过程。涉及代码或平台时，保留对理解、复用有实际影响的信息，例如已公布的功能范围或登录要求；具体检查过程和版本记录放在文档中。

### 直接叙述与自然衔接

将直接、自然的表达作为重要的定性编辑标准，适用于英文旁白、中英字幕及画面解释文字。结合上下文判断每处表达的作用，保留语言自身的节奏与变化。

- **直接展开内容。** 能直接说明定义、原因、机制或结果时，优先省去“先把……理解清楚”“我们先……，别……”“下面先……”以及 “let us first”“we will now” 等没有信息增量的铺垫。
- **让对比服务于论证。** “不是……而是……”“not … but …”“rather than”等可用于真实的概念辨析、方法差异和关键误解澄清。避免虚设一个错误观点，再通过否定它引出正文；也避免对观众反复告诫。
- **用内容关系衔接段落。** 因果、条件、递进和具体例子能够自然推动讲解。保留有帮助的开场导览、复杂推导定位和真实方法步骤，减少每段都预告下一步的惯性写法；无需机械换成另一组固定连接词。
- **将检查结果转化为必要信息。** 来源核对、指标可比性等内部检查继续执行，旁白集中交代影响理解的事实、条件与证据限定，避免逐条播报检查过程。改写时保留作者观点与解读者归纳的区别，以及原有不确定性和结论强度。

以下示例说明取舍方式，具体措辞随内容调整：

| 原表达 | 可采用的直接表达 |
|---|---|
| 先把三个缩写理解清楚。MIE 指分子起始事件，KE 指能够测量的关键生物变化，AO 指不良结局，它们处在机制链的不同层次。 | MIE 指分子起始事件，KE 指能够测量的关键生物变化，AO 指不良结局，它们处在机制链的不同层次。 |
| 这里重点看的不是模型名称，而是它怎样利用机制信息。 | 模型通过机制信息连接分子结构与毒性预测。 |
| The paper's argument is not that earlier methods cannot predict anything, but that a single label may hide biological organisation. | Earlier methods provide useful predictions. The authors argue that a single label may hide biological organisation. |

真实的辨析仍有价值，例如“该统计量是对称的，不能表示方向；上游与下游由有向边区分”。同样，“先预测事件状态，再进行图分类”表达实际计算依赖，步骤顺序应保留。

配音前结合相邻段落审读讲稿与画面解释文字：这些转折、预告或提醒是否提供必要信息，是否帮助定位或表达真实关系？删除后含义与衔接均不受损的部分，优先删去或直接改写；重要证据限定与定义仍需清楚。依据整段的信息密度、自然度和可理解性判断，不按句式出现次数或比例验收，不因出现某种句式判定失败，也不为简洁而省略关键内容。此审读沿用现有制作流程，无需新增人工批准环节。

## 研究背景、Research Gap 与 Motivation

新建完整解读时，在共同研读阶段完成以下分析；修改已有背景内容时更新相关证据与讲解。换声、字幕修复、纯画面或目录调整等局部任务不因此扩展为重新研读或重做既有视频。

1. **从 motivation 明确问题与比较依据。** 阅读 Related Work 及相关 Introduction、Background 等章节，说明作者关注什么科学或实际问题、为什么值得解决，以及任务、数据、假设或评价条件提出了哪些要求。由这些要求确定比较前人工作的维度。gap 是尚未解决的问题，motivation 是解决它的理由，方法是本文的回应；不要从方法名称或最终结果倒推缺口。
2. **按解释必要性筛选研究。** 围绕问题或研究路线组织材料，不沿参考文献或章节顺序逐篇复述。展开的研究应支撑、限定某项归纳，解释关键方法来源或对照，或提供理解本文所必需的机制。判断省去它会损失什么理解：若不影响核心论证，可合并、简述引用或留在阅读笔记中。文献核对范围可以大于视频展示范围；避免为了少讲而遗漏可能改变 gap 判断的最近工作或反例，也不自动扩展为领域综述。
3. **核对关键原始研究。** 选读支撑核心判断、代表必要路线或可能改变归纳的原始研究，核对实际方法、贡献、假设、结果与具体版本，为判断保留页码、章节或可追溯链接。仅凭标题、摘要或本文转述，不能称为已核实。数量按论证需要决定，不要求读完所有引用；阅读范围与核对状态记在已有来源记录中。
4. **比较后形成归纳。** 沿共同维度说明前人已经做到什么、在哪些条件下仍有什么具体问题，以及该问题为何影响本文的 motivation，连接到本文回应和贡献。归纳须由比较支持，不能仅列出各篇内容后追加“仍有不足”；不要把单个方法的限制推广到整个领域，不为每项研究强行安排缺陷，也不把互补路线画成单线替代关系。在英文主笔记中保留归纳、主要依据与条件，区分本文作者的评价、原始文献支持或不支持的内容及解读者的综合判断。
5. **在视频中先给归纳，再用研究作例证。** 默认按“motivation / 具体问题 → 前人进展与具体 gap 的归纳 → 必要研究作为例证 → 本文回应与贡献”展开。进入相关背景讲解时，先让观众知道前人做到了哪里、剩余问题是什么及其与当前问题的联系，再用代表研究的具体做法、条件或机制解释这一判断。每个展开的例子应让观众看出它支持或限定哪项归纳；例子结束后衔接本文回应，避免再重复一轮完整总览。结论前置指成片的呈现顺序；研读时仍先核对和比较证据，再形成归纳，不能先定 gap 再挑支持它的引用。

没有独立 Related Work 章节时，从 Introduction、Background、Discussion 或方法论证中重建上述关系。作者未明确陈述的连接标为解读者归纳；证据不足时保留不确定性，不强行为论文补造 gap 或创新主张。按本文发表时的研究背景判断其论证，后续研究单独注明时间与作用，不能用后来出现的方法否定当时的动机。

通过原始出版方、作者或机构公开版本寻找关键引用，在工程来源记录中按实际阅读范围记载核对结果。原文无法获取或只能部分阅读时，记录缺失证据，将讲解限定为“本文作者指出”或其他有依据的表述，必要时缩小讲解范围；不能把未找到反例当成已证实的创新性。原始文献与本文评价存在差异时，先比较版本、任务与适用条件，说明差异及其对 gap 和 motivation 的影响，避免照搬或无依据地否定作者结论。

可用独立背景段落，也可围绕具体问题穿插归纳与例证，不固定章节数、时长或引用数量。前置结论使用观众当前能理解的表达，必要定义随相关例子展开；关键前人机制按“Related Work 的比较与机制动画”选择。英文讲稿依据研读结果写作，关键证据与局限在旁白和对应中英双语字幕中均须准确传达，译文疑义回查依据。来源细节可压缩，工程记录仍需可追溯；局部修改更新现有记录中的相关内容。

## 画面与素材

### 画面信息与暂停阅读

先明确当前论点，以及观众需要看见什么对象、关系、证据或机制才能理解它，再选择呈现形式。画面可以通过对照、空间关系、数据或状态变化补充旁白的解释，不需要为此增加未经支持的新事实。有关判断可用简短陈述直接表达，并与支持它的内容对应；不要求每页使用同一种“结论卡片”或填写固定项目。关键词可作标题、导航和节点标签，主画面不能主要由待讲事项、接下来会出现的关键词或逐句摘取的旁白组成；字幕和侧栏的完整性也不能补足空泛的主画面。简短开场导览按既定要求保留。

按信息关系选择图形，以下是可采用的形式，不是固定页面模板：

| 解释目的 | 主画面可承载的内容 |
|---|---|
| 建立概念 | 具体例子、必要定义，以及例子中的对象与概念的对应。 |
| 比较研究 | 从具体问题导出的共同维度、可识别研究的实际做法和条件，以及比较支持的归纳与剩余问题。 |
| 解释方法 | 具体输入、变化规则与输出，通过对象或状态的变化说明关键设计如何起作用；公式配变量含义或必要算例。 |
| 解释结果或消融 | 可比较对象、改变的因素、指标与条件、实际数据及其支持的判断，让差异和结论边界可见。 |
| 交代边界或总结 | 具体主张、对应证据及适用范围，保留影响判断的数值或条件。 |

默认支持暂停后充分阅读：用完整而简洁的陈述、图示和数据保留重要信息，已讲过的比较行或条件尽量留在画面中，通过高亮引导当前注意点，并在解释完成后留下稳定、完整的状态。内容过多时拆成有共同参照的页面，保持可读字号；不把整段旁白贴满屏幕，也不要求正常播放时读完所有补充信息。旁白解释关键关系，中文字幕仍忠实对应实际英文语音。

保持标记和颜色含义一致，让动画作用于正在讲解的对象，显现实际状态变化、变量影响、关键差异或证据关系。箭头应表达明确的数据流、时间顺序、候选转移或推理关系，避免把并列事项自动连成流程。静态表格和图示可以稳定展示；一个主画面可以跨多个旁白段落，实际方法过程仍可逐步展开。持续运动、逐卡亮起或跟着段落切换标题本身不构成解释。动作与停留须遵循“语义动作与动画触发”，与语音实际讲到的对象和步骤对应。

### Related Work 的比较与机制动画

需要比较多项相关研究时，优先考虑表格：比较维度来自 motivation 对应的具体问题，行按必要研究或路线组织，内容体现它们如何解决问题、做到什么程度及在哪些条件下仍有 gap。先展示有依据的简短归纳，再用可比较单元格、分组或标注解释它；表格完整不等于已完成归纳。维度可包括候选生成与保留、训练目标与评价协议、理论假设与保证范围，不强制统一列数或“优点／缺点”栏目。单元格用能说明对象和行为的短句，避免把空泛关键词搬进表格。研究身份与引用可识别，贡献、条件和角色来自已核对材料，不把理论启发、经验基线和互补路线混为同一种比较。

通过必要性筛选的关键前人研究可独立安排机制动画：当其机制是理解本文方法的前提、判断关键对照差异的依据，或解释重要实验与争议结论所必需时，用具体对象、状态变化或算例说明它如何支撑或限定前置归纳。只承担研究定位作用的引用可保留简短标注，不逐篇展开。动画标注对应研究与教学示意，机制结束后接到本文设计；可采用“归纳与比较 → 必要机制例证 → 本文回应”，也可在首次需要机制的位置嵌入，避免重复建立情境，不固定数量或时长。

介绍前人研究、相关背景或引用结果时，让引用与内容紧密对应：在表格行、论述或图示附近保留方法名及 `Author et al., Year`，用“前人研究 / Prior work”等简短标识说明角色。首次介绍以紧凑文献区、表下注释或文献卡片展示作者、年份、题目和发表载体；长条目可分行或分次展示，留出阅读时间，使研究内容占据主要空间。再次引用可使用简短作者年份标注。书目与解释的对应关系应清楚，旁白无需朗读整条书目。

完整参考文献与英文主笔记中的条目一致，保留可追溯链接。清楚区分前人研究、本文结果与教学示例，避免将引用研究的图表或结论误认作本文成果；引用完整不等于研究机制与贡献已经解释充分。

### 图表与素材来源

原论文图像保留必要坐标、图例和来源，裁切与放大应有标注。重绘图表记录数据来源，教学示意明确标为示意；新增教学例子先核对定义与计算。字体、许可和必要图形存入本篇工程，减少渲染时的外部依赖。

画面和字幕允许自然中英混排。优先保留论文题目、人名、数据集、方法和指标的原名；首次出现可配中文解释，后文使用读者更容易跟上的表达。长英文标题、姓名和方法名检查实际渲染宽度，不能只依靠字符数推断不会溢出。

## 声音、时间轴与字幕

先复用用户明确选择或认可的英式英语声音参数。未另指定时，以 Ryan `en-GB-RyanNeural` 为声线起点；语速按当前内容和偏好决定，不继承另一论文的固定参数。新声音、语速变化或明显发音问题，可以制作包含目标语言句子、专名及数字的短试听，并邀请反馈；这不是每次制作都必须等待批准的关卡。用户明确要求先试听确认时，等待该反馈再进行依赖它的整片合成。

完整讲解段落比逐句小块合成更容易保持语气连续。按旁白段落保存原始音频、服务返回的时间信息和参数；缓存标识包含配音语言、英文文本、声线、语速及影响输出的引擎配置。修改英文旁白时只重做受影响段落，其余音频保持原样；仅修订中文字幕时复用对应音频。服务失败采取有限重试，例如最多三次，并保留现有成片；不可无说明地换回用户否定的音色。

从解码后的实际采样数确定段落长度，再换算成帧数。片头、段间与片尾停留明确进入同一时间轴。48 kHz 配合 30 fps 时每帧是 1,600 个样本，这只是方便的组合；其他帧率须正确处理累计舍入误差。

优先使用英文 TTS 的词语时间信息或可靠的强制对齐结果，先核对返回文字、英文讲稿与实际语音，再将英文原句和对应中文译文共同绑定到英文语音片段。不能用中文字数或总时长平均分配字幕，也不能把缺失或错配元数据当成准确时间。

按完整含义将英文原句与中文译文组织为成对字幕单元，共用起止时间。为阅读拆分或合并时，同步调整两种语言及对应语音边界，保持语义范围一致，不因一侧过长而省略另一侧。提示条边界不能切开英文 TTS 的词语，行内换行保护英文单词、`higher-order` 一类连字符词、缩写及连续数字，避免行首孤立标点。画内字幕与双语 SRT 从同一份字幕数据生成，共用文字、时间和断行。默认导出与画内显示一致的中英双语 SRT；英文或中文单语 SRT 按需从同一时间轴导出。

每条最多两行、每行不超过 28 字符是既往 1080p 版式的可调案例参数，不是所有双语字幕的统一限制。检查两种语言的实际字号、行数、显示时长、画面宽度及字幕区域高度；遇到长句或术语时，优先按语义同步拆分字幕单元并调整布局，保持可读字号，不截断词语。

字幕、章节、片尾总时长和封面时长由最终时间轴产生。不要修改旁白后继续使用旧字幕，也不要在封面写死上一版片长。

### 语义动作与动画触发

配音段落、字幕提示和动画动作按各自用途组织。一段配音或一条字幕中若讲到多个事件、对象或步骤，应安排相应的多个视觉动作；按完整段落合成声音不限制动画粒度。使用英文 TTS 词语时间信息或经核对的强制对齐结果，将关键动作绑定到具体词句，不能把段落序号直接当作事件时刻，也不能仅按段落时长平均分配动作。

在现有分镜或时间轴中明确关键动作的触发词句、对应时间和应呈现的对象或状态，例如当前事件、应高亮的边、可用历史、当前预测步骤或正在比较的数值。字段、动作数量和组件结构按工程需要决定，不固定每段阶段数。必要背景可提前呈现，但讲到关键对象时，应能在主图中准确定位；段落进度条和装饰运动不能替代有含义的状态变化。

讲解从教学例子转到论文协议、从历史观测转到当前预测或从一个数据集转到另一个时，主图应同步切换或明确区分对应内容。仅更换字幕、侧栏卡片或底部标签不足以表达主图中尚未体现的变化。复用组件时，按当前英文配音重新核对触发点；讲稿、语速、字幕断句或分镜变化后复查受影响的语义对应。

## Remotion 渲染与交付

查看工程的 package 配置、composition、渲染入口和浏览器选择。新建工程注册用于最终成片的 composition，读取英文音轨、对应中英双语字幕、时间轴和素材引用；按需保留封面或预览 composition，不为中文配音另建必交视频。没有专门的 Remotion 插件时，使用本地 CLI 或 renderer API 即可，不把工具名称当成完成证据。

已有项目保持其版本与经过验证的浏览器组合；新项目先验证兼容性，再锁定依赖。浏览器加载超时时，检查实际路径、版本、启动日志和最小样片，不反复盲试，也不未经说明全局更换系统浏览器。本次 Chrome 149 的记录仅作为特定环境的排障线索。

字体、长标题、中英双语字幕和复杂图表先用代表帧检查。静态画面正确后，渲染短样片检查动画、素材加载、发音重点和音画同步。完整输出先写入独立暂存文件，确认满足约定后发布为主交付文件，保留用户要求保留的旧版。

验收按实际风险选择，通常包括：

- 内容与时序：来源、关键数值、英文讲稿完整性、英文字幕与实际旁白一致、中文译文的语义覆盖及双语字幕单元对应、字幕无重叠或越界、章节与总时长一致；核对整片实际时长与当次要求或设计目标，并按“简短开场导览”核对从首帧到正文开始的实际时长，在已有记录中记载。按“核心内容与时长”“直接叙述与自然衔接”和“成片内容与制作记录”检查表达与信息取舍，保留重要科学限定。
- 入门理解：核心术语有解释，方法输入与输出、关键步骤及指标含义能够沿例子理解；检查论证中的知识跳跃和必要的阅读停顿。
- 背景论证：检查第一个展开的历史例子出现前，观众能否知道与 motivation 相连的前人进展归纳及具体 gap；每项展开的研究是否提供必要依据、限定或机制，比较是否收敛到本文回应与贡献。删去某个例子不影响核心理解时考虑合并或移入笔记。回查关键原始研究与可能改变判断的最近工作，确认归纳有依据、作者评价与独立核对及综合判断未混淆，重要条件与证据局限得到体现。
- 主画面信息：抽查 related work 比较、方法机制和关键结果等适用场景，暂时遮住字幕并忽略待讲事项标题，检查是否仍能辨认当前判断所需的具体对象、关系、证据或条件。相关研究表应展示支持归纳的比较，方法动画应解释关键变化，结果画面应呈现数据与结论的联系；只播报接下来讲什么或只列名词的画面应重做。暂停检查代表性解释完成状态，并连续检查关键机制，不要求静帧替代完整讲解。若只替换论文名称就能用于许多无关研究，应回查内容是否过于泛化；这是定性审读，不按关键词、表格数量、运动频率或字数判定。
- 音频：段落无缺失、无削波或异常长静音；检查关键英文词和数字，明确人工听审的覆盖范围。
- 视频与时间同步：分辨率、帧率、帧数、时长、音视频编码及全片解码；在多个位置核对成片音轨与最终配音时间轴一致，并核对两种字幕与英文音轨的对齐及成对起止时间。
- 动画语义对应：按关键语义转换选择位置，检查触发前后，并连续检查核心过程片段；逐项核对旁白提及的对象、时刻、数值、步骤和上下文是否与主图一致。覆盖段内多次推进、关键对象出现及讲解对象切换，不能只取每章首段或每阶段固定位置的静帧。字幕和侧栏同步不能代替主图检查。
- 画面布局：代表分镜、变化较大的布局、封面和片尾；核对比较表、引用区域、图表与中英双语字幕的对应关系、字幕布局及可读性，避免字幕遮挡关键内容；检查解释完成后是否保留可暂停阅读的完整状态，以及制作标签是否混入成片。需要时对照成片抽帧与已检查静帧，允许正常有损压缩差异。
- 交付：记录视频与中英双语 SRT 等最终文件的哈希、渲染参数、来源和已执行检查；核对核心内容覆盖与事实一致性。确认英文主笔记包含论文理解、视频设计、参考文献、实际时长和有效成片入口，能够支持后续回顾。分别记录音轨语言、字幕语言集合和成片数量；技术检查、翻译核对和人类反馈分别标明，不能用音轨通过代替字幕内容核对。

在已有验收记录中分别写明音轨时间同步、字幕对齐、动画语义对应和主画面信息检查的结果、覆盖片段及未检查范围。解码、波形比对、成片与预渲染静帧一致、布局检查分别证明各自检查项，不能据此推断动画内容与讲解含义对应；语义同步通过也不能证明画面解释充分。局部检查不能写成全片连续听审。

默认可以从 1080p、30 fps、H.264/AAC 开始，已有要求优先。交付一个带英式英语配音和画内中英双语字幕的视频、对应双语 SRT、封面及可编辑工程；英文主笔记、英文讲稿、字幕译文、分镜、章节与来源文档随内容同步。首次制作的交付物验收通过后，按 [完成归档](library-management.md#完成归档) 将 PDF 从 `candidate_paper/` 移入 `paper/`，核对哈希，更新来源路径和台账，再核对实际交付入口。明确单视频播放入口和章节跳转，以及预览、重新生成与导出的方式；默认无需语言切换或双版本对比播放器。说明本轮服务是否已停止。不要停止其他会话启动的服务。

## 增量修改

先确定受影响的英文旁白、中英字幕、动画或文件入口。复用合格英文音轨及未变素材，只修改中文字幕时不重新合成配音；英文内容或语速改变时同步检查译文、时间轴和动画。若修改历史多版本工程，只处理当前授权范围，涉及共用事实或组件时检查依赖影响，不自动删除或补做其他版本。

| 请求 | 优先处理 | 复查重点 |
|---|---|---|
| 换声或调语速 | 保留内容，重新生成所需旁白与时间轴 | 新试听范围、字幕对齐、时长变化 |
| 只改中文字幕 | 复用英文音轨，修订译文及必要的双语配对、断句和时间边界 | 翻译准确性、双语配对与音画语义对应、双语 SRT 与画内字幕一致 |
| 保留英文原名 | 修改相关旁白、标签、断句与换行 | 专名拼写、发音、长文字宽度 |
| 调整开场导览 | 压缩或补足简短书目与路线，遵循“简短开场导览”的合计时长目标 | 实际开场时长、正文位移、章节、总时长、避免重复介绍 |
| 只改画面 | 沿用既有音轨，按需要调整视觉动作及其触发点 | 受影响布局、语义对应与编码输出 |
| 移目录或清理 | 保留当前内容与交付文件 | 路径、运行环境、哈希、校验和文档依赖 |

重生成配音后不要继续断言“全部旧段落未变”：区分改文段落与未改文段落，按实际范围比较。已有声音偏好持续有效，不因小改动反复请求同一项确认。同步更新英文主笔记中受影响的理解、设计、时长或交付入口；更新技能本身不触发历史视频重做或历史笔记补建。

## 多论文目录与清理

工作区以 `candidate_paper/` 接收并保留待制作与制作中的 PDF，以 `paper/` 保存已完成视频生成与验收的 PDF，以 `remotion/` 管理各论文工程与成片。每篇论文沿用一个工程，默认交付一个英式英语配音、中英双语字幕的视频。先按 [论文库管理](library-management.md) 核对工具兼容性并完成编号、日期与统一台账登记；完成后再按该参考归档。默认结构如下，编号和日期仅为格式示例；`en-gb` 标识配音语言，中英双语字幕与该视频放在同一输出目录：

```text
workspace/
├── candidate_paper/                    # 待制作与制作中的 PDF
│   ├── Original paper title.pdf        # 用户投递、尚未登记
│   ├── P0002__pending__完整英文题名.pdf  # 已登记、尚未开始
│   └── P0003__YYYY-MM-DD__完整英文题名.pdf # 制作中
├── paper/                              # 已完成视频生成与验收的 PDF
│   ├── catalog.json                    # 统一登记候选、制作中和已完成论文
│   ├── README.md                       # 生成的统一阅读入口
│   └── P0001__YYYY-MM-DD__完整英文题名.pdf
└── remotion/
    ├── _library/                       # 工作区管理工具与迁移记录
    ├── conclusion/                     # 按需保存 W 编号与完整日期范围的周总结
    ├── P0003__YYYY-MM-DD__完整英文题名/  # 制作中的工程，采用下述同类结构
    └── P0001__YYYY-MM-DD__完整英文题名/
        ├── 项目配置与依赖                 # 一套 Remotion 配置与依赖
        ├── src/                          # 图形组件、成片 composition 与时间轴
        ├── content/en-gb/                # 英文讲稿、中英字幕与分镜
        ├── public/                       # 字体、图形等素材
        │   └── audio/en-gb/              # 英式英语配音
        ├── docs/                         # 来源、制作与验收记录
        │   └── paper-notes.md            # 英文论文理解与视频设计主笔记
        ├── out/en-gb/                    # 单个成片、中英双语 SRT、封面及验收记录
        ├── .cache/                       # 渲染环境与语音缓存
        └── scripts/ 与 tests/            # 按项目需要保留
```

来源记录、英文主笔记和统一台账共同关联指定 PDF 与工程；PDF 路径随实际阶段指向候选或完成目录，归档只改变 PDF 父目录，不改变编号、开始日期、文件名或工程位置。编号、日期和归档规则以“论文库管理”为准。原始题名保留在论文记录及讲解中，避免把文件命名规则带入旁白。按脚本的实际解析基准计算 PDF 相对路径，兼容已有嵌套工程。

一个工程管理依赖、字体、图形、来源、英文音轨及对应中英双语字幕；文件名或元数据分别记录配音语言与字幕语言集合，不能仅凭 `en-gb` 目录名推断字幕为单一语言。同一工程保存两种字幕语言，无需另建中文配音子工程。此规则用于新工程，已有历史目录按授权范围沿用或迁移，不以更新技能为由移动当前项目。

目录迁移按“论文库管理”的迁移、验收与回滚流程执行，验证通过后再清理明确不再需要的文件。

删除当前任务自行生成且不再需要的临时文件可以作为收尾；既有旧版、归档和运行环境的删除遵循用户授权与保留要求。检查实际引用后区分：

- 当前交付和编辑所需内容：视频、字幕、封面、主音轨、英文主笔记、来源、源码、图形、字体和许可。
- 继续运行所需内容：已安装依赖、经验证的浏览器，以及用户选择保留的当前配音缓存。
- 可清理过程内容：不用的旧版、试听、审阅截图、临时转换文件、渲染 bundle、下载压缩包和未引用的缓存。

清理后更新检查脚本和交付清单，不能再强制读取已删试听或旧归档。历史验收可保留摘要，但应注明对应过程文件已清理。重新核对保留项哈希和目录入口。报告释放空间时使用前后相同口径的实际占用，不把多次临时复制和删除累计成净节省量。
